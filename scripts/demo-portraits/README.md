Optional portraits for demo profiles.

Add JPG, PNG or WebP files to `female/` and `male/`, then run `npm run clear:demo` and `npm run seed:demo`.
They are assigned to demo profiles in file-name order.

Only use images you have the right to use for this purpose: licensed generated portraits of fictional people,
or photos of people who agreed in writing. Never use photos of real people taken from the internet.
